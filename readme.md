## ⚡ Overview

**Ayliz.dev** is a personal portfolio and digital product gallery engineered from the ground up to reflect modern web aesthetics, performance, and internationalization. Designed for seamless navigation, it combines clean UI architecture with high-impact micro-interactions.

---

## ✨ Key Features

### 🌍 Multi-Language Engine (`i18n`)
- Built-in multi-language dictionary matrix supporting **English**, **Turkish**, **German**, and **Korean**.
- Integrated directly into the initial splash screen setup.
- Persistent state management powered by `localStorage` and dynamic asynchronous DOM updates.

### 🌓 Adaptive Dark Mode
- Theme switching with native system preference detection (`prefers-color-scheme`).
- Smooth CSS custom properties state switching without layout reflows or flashes of unstyled content.

### 📱 Responsive Layout
- Fluid grid structures powered by Tailwind CSS.
- Mobile-first approach ensuring optimal layout across viewports from ultra-wide displays to mobile devices.

### 🎨 Micro-Interactions & Custom UI Elements
- **Custom Interactive Cursor:** Dynamic magic cursor featuring subtle heart/paw bubble effects on movement.
- **Playful Animations:** Custom animated feline micro-illustrations pinned to the footer area.
- **Iconography & Typography:** Scalable Lucide iconography coupled with a balanced pairing of *Outfit* and *Plus Jakarta Sans*.

### 📂 Dynamic Project Filtering
- Client-side JavaScript filtering engine for instant project categorization without page reloads.
